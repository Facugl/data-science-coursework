\ejercicio{Inicio de sesi\'{o}n}
Solicitar al usuario los datos de inicio de sesi\'on: Nombre de Usuario y Contrase\~na. Validar los datos ingresados:
\begin{itemize}
    \item Si el nombre es \textit{``Franco''} y la contrase\~na \textit{``2022''}, mostrar \textit{``Bienvenido Franco! Inicio de sesi\'on v\'alido!''}.
    \item Si el nombre es incorrecto, mostrar \textit{``Nombre de usuario incorrecto, no se puede iniciar sesi\'on!''}.
    \item Si la contrase\~na es incorrecta, mostrar \textit{``Contrase\~na incorrecta, no se puede iniciar sesi\'on!''}.
    \item Si ambos son incorrectos, mostrar \textit{``Usuario totalmente desconocido! Fuera hacker!!\''.}
\end{itemize}
