\ejercicio{Crear clase Persona}

Crear una clase "Persona", con los siguientes atributos:
\begin{itemize}[itemsep=0.2em]
    \item \textbf{IdPersona:} num\'erico entero
    \item \textbf{Dni:} num\'erico entero
    \item \textbf{Apellido:} cadena de texto
    \item \textbf{Nombre:} cadena de texto
    \item \textbf{Edad:} num\'erico entero
    \item \textbf{G\'enero:} texto
    \item \textbf{Peso:} num\'erico con decimales
    \item \textbf{Altura:} num\'erico con decimales
    \item \textbf{Domicilio:} cadena de texto
\end{itemize}
