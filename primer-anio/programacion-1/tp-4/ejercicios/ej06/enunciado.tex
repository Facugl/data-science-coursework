\ejercicio{Clase ejecutable con interacci\'on del usuario}

Crear una clase ejecutable que haga lo siguiente:

\begin{enumerate}[label=\alph*), itemsep=0.5em]
    \item Pedir al usuario el ingreso de los datos de 3 Personas, creando para cada una de ellas un objeto.
    
    \item Para cada objeto deber\'a comprobar su IMC mostrando el resultado.
    
    \item Para cada objeto deber\'a calcular si es Mayor de Edad, mostrando el resultado.
    
    \item Para cada objeto mostrar la info del mismo.
\end{enumerate}
