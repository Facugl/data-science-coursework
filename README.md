## 🚀 Getting Started

### Prerequisites
- LaTeX distribution (TeX Live, MiKTeX, or MacTeX)
- Git
- A LaTeX editor (VS Code with LaTeX Workshop recommended)

### Clone the repository
```bash
git clone https://github.com/Facugl/data-science-coursework.git
cd data-science-coursework
```

### Compile a document
```bash
cd primer-anio/programacion-1/tp1
pdflatex programacion1-tp1.tex
pdflatex programacion1-tp1.tex  # Run twice for ToC
```
